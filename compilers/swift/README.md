# Swift browser compiler

Swift's C++ driver, frontend and Wasm LLD run in one resident pthread-enabled
WebAssembly module. SDK defaults keep `swiftc` commands short. Programs link a
normal single-threaded static Swift standard library; this is not Embedded Swift.

See [summary.md](summary.md) for source pins and patches, and
[tutorial_swift.md](tutorial_swift.md) for usage. The verified host is macOS arm64
with Xcode command-line tools and native Swift. Emscripten is 6.0.8.

## Build

Create and activate `compilers/swift/environment-build.yml`, then set
`WASMBOLT_EMSDK_ROOT="$CONDA_PREFIX/opt/emsdk"`. From `compilers/swift`:

```sh
bash scripts/00-fetch-sources.sh
bash scripts/10-native-tools.sh
bash scripts/20-configure-wasm-llvm.sh
bash scripts/25-cmark.sh native
bash scripts/25-cmark.sh wasm
bash scripts/30-configure-swift.sh native
bash scripts/35-build-native-compiler.sh
bash scripts/32-build-wasm-llvm.sh
bash scripts/38-configure-stdlib.sh guest
bash scripts/38-configure-stdlib.sh host
bash scripts/39-build-stdlib.sh guest
bash scripts/39-build-stdlib.sh host
bash scripts/30-configure-swift.sh wasm
bash scripts/40-build-compiler.sh
python3 scripts/50-package.py
```

Dedicated pinned checkouts and all build outputs stay in `.work/`.
`WASMBOLT_SWIFT_WORK_DIR`, `WASMBOLT_SWIFT_SOURCE_ROOT` and
`WASMBOLT_SWIFT_LLVM_SOURCE` select existing compatible inputs; jobs default to
six through `WASMBOLT_SWIFT_JOBS`. Tool paths can be overridden with
`WASMBOLT_CMAKE`, `WASMBOLT_NINJA`, `WASMBOLT_NODE` and `WASMBOLT_PYTHON`.

## Serve

From the repository root:

```sh
python3 compilers/swift/scripts/70-stage-site.py --swift-only --site build/swift-only
python3 scripts/serve.py --site build/swift-only --port 8775
```

For the full WasmBolt interface, use `--base-site site --site build/swift-site`
instead. The base site is generated by the normal root build. The dedicated
preview uses the same UI; it omits Clang and LLVM utility downloads. Debugger
controls remain disabled until the separate Swift LLDB layer is installed.

## Validate

From `compilers/swift`:

```sh
npm install --no-package-lock
npx playwright install chromium
node tests/prepare.mjs
node tests/compiler.mjs
node tests/compiler-browser.mjs
```

Set `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` for an existing Chrome installation.
The browser gate covers AST/SIL/IR/assembly, objects, linking, strings and arrays
at all three optimization levels. Reports stay in ignored `.work/`.
